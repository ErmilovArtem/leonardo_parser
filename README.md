## leonardo_parser

Проект реализует парсинг сайта Леонардо (https://leonardo.ru/) с интерфейсом в виде telegram бота. Есть миграции alembic для облегченного создания таблиц БД
Предусмотренны обходы блокировок Cloudflare и обход 503 ошибки при множественных запросов.
В parser/cookies есть настройки позволяющие считывать со страницы с товарами сразу 120 элементов и устанавливающие сортировку по дате.
Благодаря сортировке по дате реализовано дополнение базы данных для более быстрого парсинга. 

Спроектированно так, чтобы, гипотетически, при падении парсера не падал телеграмм бот. При падении парсера на половине, и перезапуске парсинг не должен проходить заново.

Скорость парсинга одной категории с обходом всех блокировок около 20-ти минут
